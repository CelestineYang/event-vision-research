# 第二阶段结果简要总结

完成22项同缓存评估、Static Fusion+Frame单参数对照，以及Current/GRU/Conditional的三种子实验（每次80轮）。
每次均按原Test视频NLL选择checkpoint；不是独立测试。

| 方法 | 视频Top-1 | 视频NLL（均值±样本标准差） |
|---|---:|---:|
| Current，3 seeds | 96.3209%（三次相同） | 0.196445 ± 0.002217 |
| GRU，3 seeds | 96.3209%（三次相同） | 0.196322 ± 0.001016 |
| Conditional，3 seeds | 96.3209%（三次相同） | 0.197241 ± 0.000892 |
| Static Fusion+Frame，seed0，epoch8 | 96.2035% | 0.193643 |
| 三图像头概率平均 Frame | 97.1037% | 0.280180 |
| 固定 Fusion+Frame，等权 | 97.0254% | 0.217572 |

九个动态模型纠错集合相同：相对同缓存Fusion A均纠正7个视频、无新增错误。
Memory未增加正确样本；seed0逐窗口重置历史后准确率不变、NLL略改善。
这不证明Memory普遍无效，只说明当前设置尚无额外准确率收益的证据。

相对新静态图像旁路，动态模型共同纠正4个视频、损失1个，净增加3个。
静态较低的平均NLL主要来自双方都预测错误的视频，不能解释为大多数视频都更好。
Current在2354个视频上NLL更低，静态在196个上更低，5个近似相同。

多种子只改变动态初始化和训练顺序；专家及unrestricted Static初始化固定，
不代表整个系统重训方差。前缀评估尚未执行。没有新增架构或联合微调。

## 快照内容

- `summary.json`：各选中epoch、指标及三种子统计。
- 各模式目录：实际配置、80轮完整指标、完成状态及选中模型逐视频预测。
- `suite/`：22项评估指标、配置、审计和配对概览。
- `static_frame_comparison/`：静态旁路与动态模型的配对、NLL贡献及极端样本。
- `sources.json`：真实来源和SHA256；权重仅列路径及校验值，不上传。

不含数据集、证据缓存、模型权重或完整概率数组。路径是原服务器路径，迁移后需映射。
